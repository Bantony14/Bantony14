## 🚀 Featured Project

### 🏠 RentFlow – Rent Management System

A full-stack rent management application designed to manage
tenants, rooms, rent payments, receipts and administrative operations.

**Key Features:**

- 🔐 JWT Authentication
- 👨‍💼 Admin Dashboard
- 👤 Tenant Portal
- 💰 Rent Management
- 💳 Razorpay Payment Integration
- ✅ Payment Verification
- 🧾 PDF Receipt & Invoice Generation
- 📧 Email Notifications
- ☁️ Cloudinary Integration
- 🔎 Search & Filtering
- 📄 Pagination
- 📊 Dashboard Charts

**Tech:** React • Redux Toolkit • Tailwind CSS • Node.js • Express.js • MongoDB • JWT • Razorpay
